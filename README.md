# MONARCH — Premium Car Collection

A responsive luxury automotive showroom built with React, Vite, Tailwind CSS, React Router, Framer Motion and Lucide React.

## Requirements
- Node.js 18 or newer
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL shown by Vite (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## Included features
- Cinematic responsive homepage and featured vehicle cards
- Search, category filters and price sorting
- Car details pages with specifications
- Wishlist and comparison saved in LocalStorage
- Test drive and enquiry forms with client-side validation
- Brand/category browsing, About, Contact and FAQ pages
- Responsive navigation and motion effects

## Notes
This is a frontend demo. Test-drive and enquiry forms show local success feedback and do not send information to a real dealership. Vehicle data and prices are sample content. Vehicle photography loads from Unsplash and therefore requires an internet connection.
